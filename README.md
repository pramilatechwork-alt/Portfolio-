# Pramila Kumari — Portfolio Website

A responsive personal portfolio starter built with HTML and CSS.

## Files
- `index.html` — page content and a small mobile navigation script
- `style.css` — layout, colors, typography, and responsive styles

## Run locally
Open `index.html` in a browser. No build tools are required.

## Before publishing
1. Verify every personal detail in `index.html`.
2. Update education information in the About section.
3. Keep only skills you can honestly demonstrate.
4. Replace practice/sample project descriptions with your actual work where needed.
5. Confirm the email address is the one you want to publish.
6. Do not add certificates, achievements, or project claims that are not true.

## GitHub Pages
Create a GitHub repository, upload these files, then open the repository's Settings → Pages and enable deployment from the main branch (root). GitHub will provide the published URL after deployment.

## Push to GitHub

For a new local repository, run these commands from the project folder:

```bash
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/pramilatechwork-alt/Portfolio-.git
git push -u origin main
```

If this folder is already a Git repository, use:

```bash
git add .
git commit -m "Update portfolio"
git branch -M main
git remote add origin https://github.com/pramilatechwork-alt/Portfolio-.git
git push -u origin main
```
